# 08 — Prompt de inicio para Codex

Lee `AGENTS.md` y todos los documentos de `docs/` antes de actuar. Implementa el challenge de Interseguro de forma autónoma de principio a fin, respetando la arquitectura, los contratos, el plan de commits y los criterios de aceptación. Si el PDF original está presente, úsalo como fuente principal y señala divergencias con la especificación. Ejecuta tests, Docker Compose, CI y un smoke test real. Haz commits auténticos por fase, sin falsificar evidencias. Puedes usar herramientas y acceso al entorno para desarrollar, pero **no realices compras, altas de servicios de pago, cambios de facturación, exposición de secretos, borrados remotos ni push forzado sin mi aprobación explícita**. Si necesitas credenciales o permiso para despliegue, pregunta solo por esa acción y continúa con lo demás. Al terminar, entrega un reporte con árbol de archivos, SHA de commits, resultados de pruebas, URL pública verificada, costos previstos y limitaciones. No afirmes haber desplegado si no se ha comprobado.
